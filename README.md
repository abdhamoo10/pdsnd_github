# US Bikeshare Data Analysis

### Date created
This project and README file were created on June 25, 2026.

### Description
This project uses Python to explore data related to bike share systems for three major cities in the United States: Chicago, New York City, and Washington. It provides an interactive terminal experience where users can filter the data by city, month, and day to compute descriptive statistics such as popular travel times, popular stations, trip duration, and user info.

### Files used
* `bikeshare.py` - The main Python script containing the project logic.
* `chicago.csv` - Data file containing bike share information for Chicago.
* `new_york_city.csv` - Data file containing bike share information for New York City.
* `washington.csv` - Data file containing bike share information for Washington.
